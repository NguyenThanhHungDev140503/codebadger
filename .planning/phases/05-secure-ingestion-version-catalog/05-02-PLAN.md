<threat_model>
### Threats
- SSRF/host smuggling and Git option injection.
- Credential leakage via subprocess arguments, environment, config, logs, or errors.
- Malicious repository symlinks and cross-project workspace access.
- Concurrent update races and partial snapshot publication.

### Mitigations
- Exact provider allowlist + ref validation, `shell=False` argv, isolated workspace, ephemeral credential handling, per-project lock, atomic promotion, redacted diagnostics, and source-tree confinement.

### Residual risk
- Git itself and the Docker/Joern host remain trusted execution dependencies; full untrusted multi-tenant sandboxing is Phase 8 scope.
</threat_model>
